# Legal Document Management System

### Installation 
1. open the github link 
```
https://github.com/Babu1208/HackNova
```
2. download the .zip file 
3. create a folder of desired name (let "abc") and then further create a folder named "src" and unzip the github file inside "src" folder go back to "abc" and press "Shift + right click" and then open with VScode.
> note - make sure the directory should look like this "__./abc/src/all_unziped_html_css_files__"
